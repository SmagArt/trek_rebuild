# Трек под глушилкой (trek_rebuild)

Когда GPS глушат, часы считают дистанцию по шагам и рисуют на карте ерунду. Эта страница берёт файл тренировки (FIT) и маршрут — нарисованный трек или встроенную клубную трассу — и возвращает FIT с правильной дистанцией, темпом и картой.

- **Ничего не теряется.** Пульс, каденс, мощность, динамика бега, данные Stryd и модель часов остаются как были. Меняются только координаты, дистанция и скорость.
- **Файлы не уходят с устройства.** Расчёт идёт в браузере (Python через [Pyodide](https://pyodide.org)), сервера нет.
- **Любые часы.** Garmin, Coros, Suunto, Wahoo, Amazfit — всё, что пишет FIT. ZIP «оригинала» из Garmin Connect и Strava тоже подходит.

## Как пользоваться

1. Достань файл тренировки: в Garmin Connect или Strava — «Экспорт оригинала».
2. Выбери трассу из списка или нарисуй свою в [gpx.studio](https://gpx.studio/ru/): от старта до финиша, по ходу движения.
3. Нажми «Исправить», проверь карту и скачай файл.
4. Удали старую тренировку и залей новый файл: Garmin Connect → «Импорт данных», Strava → [strava.com/upload/select](https://www.strava.com/upload/select).

## Как это работает

Форма маршрута берётся из трека. Часы только раскладывают его по времени: где быстрее, где медленнее, где стоял. Если GPS иногда пробивался, точки привязываются к треку, и раскладка становится точнее: на тестах сдвиг 4–16 м при пробоях раз в 15 минут против 30–50 м вслепую.

## Локально

```
py -X utf8 cli.py тренировка.fit --route naberezhnaya -o исправленная.fit
py -X utf8 cli.py --routes
py -m http.server      # страница на http://localhost:8000
```

Тесты: `tests/test_roundtrip.py` (кодек FIT без потерь), `tests/test_foreign.py` (глушилка на чужих часах), `tests/test_jammed.py` (сверка с эталоном). Образцы в `tests/samples/` — из [python-fitparse](https://github.com/dtcooper/python-fitparse).
