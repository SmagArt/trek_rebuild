# Трек под глушилкой (trek_rebuild)

**https://smagart.github.io/trek_rebuild/**

> **EN.** Fix a run or ride recorded under GPS jamming. Give it the activity file (FIT, or GPX/TCX) and the route you actually took (a GPX you drew), get back a FIT with the correct distance, pace/speed and map. Heart rate, cadence, power, Stryd and all other data stay byte-for-byte. Runs entirely in your browser (Python via Pyodide), files never leave your device. The UI is in Russian.

Когда GPS глушат, часы на бегу считают дистанцию по шагам и завышают её на 10–20%, а велокомпьютер без датчика скорости меряет её по прыгающему GPS. На карте при этом зигзаги, прыжки через реку и точки в чистом поле. Вместе с дистанцией врут темп, скорость, сплиты по километрам, рекорды и объёмы.

Эта страница берёт файл тренировки и маршрут, по которому ты на самом деле бежал или ехал, и возвращает FIT с правильной дистанцией, темпом или скоростью и картой.

- **Ничего не теряется.** Пульс, каденс, мощность, динамика бега, данные Stryd, круги и модель часов остаются как были — файл перекодируется, а не собирается заново. Меняются только координаты, дистанция, скорость и итоги.
- **Файлы не уходят с устройства.** Расчёт идёт в браузере, сервера нет. На странице стоит Яндекс Метрика: она считает только заходы и нажатия («загрузил файл», «пересобрал», «скачал»). Вебвизор выключен, содержимое файлов счётчик не видит.
- **Любые устройства.** Garmin, Coros, Suunto, Wahoo, Polar, Amazfit — всё, что пишет FIT. ZIP «оригинала» из Garmin Connect и Strava тоже подходит. Нет FIT — подойдёт GPX или TCX записанной тренировки (хуже: без шагомера темп усредняется).
- **Бег, вело, ходьба.**

## Как пользоваться

1. **Файл тренировки.** Garmin Connect (в браузере) → тренировка → шестерёнка → «Экспорт оригинала». Strava → тренировка → «…» → «Экспортировать оригинал» (только на сайте: с компьютера или в «Полной версии» в мобильном браузере). Zepp → тренировка → экспорт → FIT.
2. **Маршрут.** Нарисуй в [gpx.studio](https://gpx.studio/ru/) от старта до финиша по ходу движения и скачай GPX. Подойдёт и GPX старой тренировки по тому же маршруту без глушилки.
3. **Чему верить в дистанции:**
   - *Длине трассы* — бег и ходьба без датчика: шаги показывают, где ты ускорялся и где стоял.
   - *Длине трассы, по времени* — вело без датчика скорости: метрам из глушёного GPS верить нельзя, трасса раскладывается по времени движения.
   - *Своему датчику* — датчик скорости на колесе, Stryd: метры остаются, трасса только для карты.
4. «Исправить», проверь карту, скачай файл.
5. Удали старую тренировку и залей новую: Garmin Connect → облако → «Импорт данных»; Strava → [strava.com/upload/select](https://www.strava.com/upload/select); Zepp → импорт в приложении.

Если GPS пропадал только местами (глушат город, за городом ловит), включи в тонких настройках «Где GPS ловил — оставить свой трек»: трассой залатаются только дыры.

## Как это работает

Форма маршрута берётся из трассы, устройство только раскладывает её по времени. Где GPS пробивался, живые точки привязывают раскладку к трассе. Паузы часов остаются паузами, автокруги по километру перенарезаются по исправленной дистанции, остальные круги сохраняются.

**Точность** (тесты на чужих файлах с искусственной глушилкой):

| Случай | Сдвиг точек от настоящего трека |
|---|---|
| Бег, GPS нет совсем | медиана 30–50 м |
| GPS пробивается раз в 15 минут | медиана 4–16 м |
| GPS живой кусками, режим «оставить свой трек» | 0 м на живых кусках |
| Длинный велозаезд совсем без GPS и датчика | сотни метров — подъёмы и спуски не видны |

Итоговая дистанция всегда равна длине нарисованной трассы — насколько точно нарисуешь, настолько точно и будет.

## Ограничения

- Маршрут нужно знать: утилита не угадывает, где ты был, а раскладывает по нарисованной линии.
- Прошёл не всю трассу — нарисуй именно свой кусок.
- Из GPX без шагомера и датчика темп по километрам выходит усреднённым.
- Приложения-челленджи (MoneyRun и подобные) забирают тренировку при первой синхронизации — замена файла их не меняет.

## Локально

```
py -X utf8 cli.py тренировка.fit --gpx маршрут.gpx -o исправленная.fit
py -X utf8 cli.py заезд.fit --gpx маршрут.gpx --distance time --keep-live -o исправленный.fit
py -X utf8 cli.py --routes          # встроенные трассы (Воронеж)
py -m http.server                   # страница на http://localhost:8000
```

Без зависимостей, Python 3.11+. Для тестов нужен `fitparse`.

Тесты:
- `tests/test_roundtrip.py` — кодек FIT без потерь против fitparse;
- `tests/test_foreign.py` — глушилка на чужих часах: сохранность всех полей и точность;
- `tests/test_convert.py` — тренировка в GPX/TCX с глушилкой и паузой;
- `tests/test_jammed.py` — сверка с эталоном.

Образцы в `tests/samples/` — из [python-fitparse](https://github.com/dtcooper/python-fitparse).
